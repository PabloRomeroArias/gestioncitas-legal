# gestioncitas-legal

Páginas públicas de la aplicación **Peluquería J.** (`io.devepoler.gestioncitas`):

- `index.html` — página de soporte, que es la *Support URL* de App Store y el sitio web de la ficha de Google Play.
- `politica-de-privacidad.html` — política de privacidad exigida por ambas tiendas.

Se sirven con GitHub Pages en https://pabloromeroarias.github.io/gestioncitas-legal/

La fuente versionada de estos dos archivos vive en el repositorio privado del producto, en `docs/publico/`. Este repositorio es solo el alojamiento público: **cualquier cambio se hace allí y se copia aquí**.
